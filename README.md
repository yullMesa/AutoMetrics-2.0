Proyecto completo de Data Analysis que transforma datos dispersos (CSV/MySQL) en información accionable para la toma de decisiones estratégicas en las áreas de Recursos Humanos (RRHH), Marketing y Operaciones.

🛠️ Tecnologías y Librerías Utilizadas
Lenguaje: Python 🐍
Procesamiento de Datos: Pandas
Almacenamiento y Origen de Datos: MySQL (esquema) / CSV
Visualización y Reporting: Google Sheets / Microsoft Excel (Tablas Dinámicas y Gráficos)
